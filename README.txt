B. THIRSHA — PORTFOLIO
========================

Files:
- index.html      Main portfolio website
- profile.png     Professional profile photo

How to open:
1. Keep index.html and profile.png in the same folder.
2. Double-click index.html to open it in a browser.

GitHub Pages:
1. Create/open a GitHub repository.
2. Upload index.html and profile.png.
3. Go to Settings -> Pages.
4. Choose Deploy from a branch, select the main branch and /root folder.
5. Save and open the generated Pages URL.

The portfolio contains:
Home, About, Education, Internship Experience, Academic Projects,
Technical Skills, Soft Skills, Languages, Certifications,
Symposiums & Achievements, LinkedIn, GitHub and Contact.
